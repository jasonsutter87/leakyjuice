Option A — run the full server (local)

Zero dependencies. Needs Node 22.5+ (for built-in node:sqlite). No npm install.

git clone https://github.com/jasonsutter87/leakyjuice
cd leakyjuice

# BENCHMARK mode (black-box — no answer key served)
node --experimental-sqlite --no-warnings server.js

# TRAINING mode (turns on the hacker terminal + in-app hints)
LJ_TRAINING=1 node --experimental-sqlite --no-warnings server.js
# → http://localhost:4060

# grade it (fires every exploit)
node holdout/grade.mjs        # expect 88/88

Option B — host the browser build (static, safe to make public)

The web/ folder is a plain static site. The whole "server" — SQLite (WASM), a JWT signer (WebCrypto), an LLM, a virtual filesystem — runs client-side in a Service Worker. Deploy it to any static host. This is what you're looking at right now.

# from the wasm-port branch:
netlify deploy --dir=web --prod          # Netlify (root-served — recommended)

# or literally any static server:
cd web && python3 -m http.server 4070   # then open http://localhost:4070

Needs a root-served origin (the app + Service Worker use absolute /api paths), so Netlify / a subdomain / a user Pages site work best; a project Pages subpath needs base-path tweaks.

How the WASM trick works

web/sw.js is a Service Worker that importScripts the engine + sql.js, and intercepts the app's fetch('/api/...') calls — answering them from the in-browser engine. So the SQL injection is real (raw concat into SQLite-WASM), the JWT algorithm-confusion is real (WebCrypto), the SSRF/XXE hit a virtual filesystem — but nothing escapes the tab. No backend, no network egress, each visitor fully sandboxed.

⚠️ Safety. The browser build is safe to host publicly — no server, no real data, no egress. The Node server is a genuinely vulnerable app (plaintext passwords, leaked secrets, injectable everywhere) — host it only on a dedicated throwaway box, egress-restricted, in benchmark mode. See DEPLOY.md. And never deploy the answer key (holdout/) — it's git-quarantined so the target stays an honest black-box.
